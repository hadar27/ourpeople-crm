# Our People Hub

Build a FULL modern nonprofit ERP/CRM web application called “Our People”.

The system is designed for a nonprofit organization that manages:

- Donors

- Donations

- Volunteers

- Registered participants

- Community projects

- Suppliers

- Financial operations

- Reports and KPI analytics

The organization helps immigrants, families, women, youth and emergency-response communities through camps, social programs and aid projects.
